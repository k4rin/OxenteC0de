# 🧠 Oxente C0de — Organização de Programação

Bem-vindo à **Oxente C0de**, uma organização de desenvolvedores(as) apaixonados por tecnologia, criatividade e cultura nordestina! Nosso objetivo é aprender, construir e compartilhar soluções digitais que façam a diferença.

---

## 🌟 Sobre Nós

Somos uma comunidade de programadores(as) em formação, unidos pela vontade de crescer juntos e criar projetos que misturem inovação com identidade. Acreditamos que tecnologia pode ser acessível, divertida e transformadora — e que o código também pode ter sotaque!

---

## 🛠️ Tecnologias que usamos

- **Frontend:** HTML, CSS, JavaScript, React  
- **Backend:** Node.js, Express  
- **Versionamento:** Git e GitHub  
- **Design:** Figma, UI/UX  
- **Ferramentas de organização:** Trello, Notion
